# Contributing to Pathfinder

The canonical contribution requirements are maintained in the [Pathfinder Contributing Guide](docs/06-development/contributing.md).

Before contributing, review the following governing sources:

- [Documentation Constitution](docs/00-governance/documentation-constitution.md)
- [Repository Governance](docs/00-governance/repository-governance.md)
- [Vision Lock](docs/00-governance/vision-lock.md)
- [Glossary](docs/00-governance/glossary.md)
- [Product Principles](docs/00-governance/product-principles.md)
- [Release 1](docs/01-product/release-1.md)
- [Architecture Decision Records](docs/05-decisions/)
- [Coding Standards](docs/06-development/coding-standards.md)
- [Testing Strategy](docs/06-development/testing-strategy.md)
- [Definition of Done](docs/06-development/definition-of-done.md)

Documentation clarifications require review. User-visible behavior changes require an approved Product Decision. Architectural changes require an ADR. Contributions must preserve the Route/Reroute model, the Confirmed Fact trust boundary, Provenance, the Route Engine's sequencing authority, and the Dependency Graph's infrastructure role.
